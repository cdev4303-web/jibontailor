# জীবন টেইলার্স (Jibon Tailor) - GitHub ও মোবাইল APK তৈরি ও ইনস্টলেশন গাইড

এই প্রোজেক্টটিতে **জীবন টেইলার্স** ম্যানেজমেন্ট সিস্টেমের স্বয়ংক্রিয় **GitHub Actions APK Builder** এবং সম্পূর্ণ অ্যান্ড্রয়েড সোর্স কোড প্রস্তুত করে দেওয়া হয়েছে।

---

## 🚀 GitHub Actions দিয়ে সরাসরি APK তৈরি ও ডাউনলোড করার নিয়ম:

আপনার কম্পিউটারে ভারী Android Studio বা Java ইনস্টল করার কোনো প্রয়োজন নেই! GitHub-এর ফ্রি ক্লাউড সার্ভার নিজেই আপনার জন্য সম্পূর্ণ `.apk` ফাইল তৈরি করে দেবে।

### ধাপ ১: প্রোজেক্টটি GitHub-এ এক্সপোর্ট করুন
1. এই স্ক্রিনের উপরে ডানদিকের **Settings (⚙️)** অথবা মেনু থেকে **"Export to GitHub"** এ ক্লিক করুন।
2. আপনার GitHub অ্যাকাউন্টের সাথে কানেক্ট করে একটি নতুন রিপোজিটোরি (যেমন: `jibon-tailor`) হিসেবে পুশ/এক্সপোর্ট করুন।

### ধাপ ২: GitHub Actions দিয়ে APK বিল্ড চালান
1. আপনার GitHub রিপোজিটোরিতে যান (যেমন: `https://github.com/আপনার_ইউজারনেম/jibon-tailor`)।
2. উপরে **"Actions"** ট্যাবে ক্লিক করুন।
3. বামপাশে **"Build Jibon Tailor Android APK"** ওয়ার্কফ্লো দেখতে পাবেন।
4. ডানপাশে **"Run workflow"** বাটনে ক্লিক করে সবুজ রঙের **"Run workflow"** বোতামটি চাপুন।

### ধাপ ৩: সরাসরি `.apk` ফাইল ডাউনলোড করুন
1. ২-৩ মিনিটের মধ্যে বিল্ডটি সম্পন্ন হবে এবং পাশে সবুজ টিকচিহ্ন (✅) দেখাবে।
2. বিল্ডের নামের উপর ক্লিক করুন (Run summary)।
3. পেজের নিচের দিকে **"Artifacts"** সেকশনে **`Jibon-Tailor-Android-APK`** দেখতে পাবেন।
4. এটিতে ক্লিক করলেই জিপ ফাইলে আপনার রেডিমেড **`Jibon-Tailor-v1.0-debug.apk`** ও **`Jibon-Tailor-v1.0-release.apk`** ডাউনলোড হয়ে যাবে!
5. এটি আপনার অ্যান্ড্রয়েড ফোনে পাঠিয়ে বা সরাসরি ফোন দিয়ে ডাউনলোড করে ইনস্টল করে নিন।

## 📱 অন্যান্য সহজ উপায়সমূহ:

### উপায় ২: কোনো ডাউনলোড ছাড়াই ফোনে ইনস্টল করুন (সবচেয়ে দ্রুত)
1. অ্যান্ড্রয়েড ফোনের **Google Chrome** ব্রাউজারে অ্যাপের লাইভ লিঙ্কে প্রবেশ করুন:
   👉 **`https://ais-pre-xvaahh6dga2msv7jjvvztm-435093563543.europe-west2.run.app`**
2. ক্রোমের উপরে ডানদিকের **৩টি ডট (⋮)** মেনুতে চাপ দিন।
3. **"Install app"** বা **"Add to Home screen" (হোম স্ক্রিনে যুক্ত করুন)** অপশনে ক্লিক করুন।
4. সাথে সাথে আপনার মোবাইল স্ক্রিনে সুন্দর লোগো সহ অ্যাপ চলে আসবে এবং অফলাইন সুবিধা সহ ফুলস্ক্রিনে চলবে!

---

### উপায় ৩: PWABuilder দিয়ে ১ ক্লিকে এপিকে তৈরি
1. কম্পিউটার বা মোবাইল থেকে **[PWABuilder.com](https://www.pwabuilder.com/)** সাইটে যান।
2. আপনার অ্যাপের লাইভ লিঙ্কটি দিন:
   `https://ais-pre-xvaahh6dga2msv7jjvvztm-435093563543.europe-west2.run.app`
3. **Start** > **Package for Stores** > **Android** > **Generate APK** দিন। সরাসরি ইনস্টলযোগ্য `.apk` তৈরি হয়ে যাবে।

---

### উপায় ৪: Android Studio দিয়ে অফলাইন বিল্ড (লোকাল পিসিতে)
1. **Android Studio** ওপেন করে `jibon/android-studio-project` ফোল্ডারটি ওপেন করুন।
2. মেনু থেকে **Build > Build Bundle(s) / APK(s) > Build APK(s)** এ ক্লিক করলেই তৈরি হয়ে যাবে।

## 📂 প্রোজেক্টের ফাইল পরিচিতি:
* **`.github/workflows/build-apk.yml`**: GitHub Actions-এর স্বয়ংক্রিয় APK বিল্ডার স্ক্রিপ্ট।
* **`jibon/android-studio-project/`**: সম্পূর্ণ অ্যান্ড্রয়েড স্টুডিও প্রজেক্ট (WebView, Camera, File Provider, Icons)।
* **`jibon/pwabuilder-quick-apk/`**: ক্লাউড APK কনফিগারেশন।
* **`jibon/web-build-assets/`**: অ্যাপের কম্পাইল করা অফলাইন ওয়েব অ্যাসেট।
